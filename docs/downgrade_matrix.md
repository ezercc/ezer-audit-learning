# 降级对照

仅供学习交流。结构可以看，商业功能没有开放。下面这些开关即使设为开启，链路也会失败关闭，因为对应实现不在本仓库。

| 阶段 | 审阅版实际做什么 | 不做什么 |
| --- | --- | --- |
| resolver | 检查代码、年份、期间 | 不补全缺失字段 |
| fetcher | 读取一个本地样例 | 不连接外部数据，不使用密钥池 |
| planner | 生成一条不执行的查询 | 不拆多路查询，不修复查询 |
| normalizer | 保留营收和净利润，最多四个期间 | 不扩展科目，不延长历史 |
| router | 只允许分析和复核使用模型 | 不回退到另一个模型 |
| analyzer | 三张短卡片 | 不产出长分析 |
| gate | 记录未补数 | 不重试，不放行高置信结论 |
| industry | 返回空主题 | 不检索，不聚类 |
| outlook | 返回不可用 | 不读取长文本 |
| auditor | 给出限制说明 | 不做质量裁判 |
| api | 本机任务和清单 | 不提供生产鉴权 |

提示词仍是短文本。远程模型只可能参与分析和复核，输出继续被截断。
